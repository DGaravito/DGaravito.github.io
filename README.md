# DGaravito.github.io
Repository for [my personal GitHub page](https://dgaravito.github.io/).

Built with plain, semantic HTML and a single stylesheet (`css/main.css`) — no JavaScript or icon kits required.
The design follows the reader's system light/dark preference, respects reduced-motion settings, and meets WCAG AA contrast.
A mockup of the current design is in `mockup/redesign-mockup.png`.
